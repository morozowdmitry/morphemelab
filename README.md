# MorphemeLab

Веб-сервис для лексикографов, составляющих морфемные словари, и исследователей,
оценивающих модели морфемной сегментации. Модель предлагает разбор слова,
лексикограф выбирает вариант или редактирует границы и типы морфем.

Планируемый адрес: **https://morphemes.mca.nsu.ru/morphemelab/**.
Приложение, база данных и инференс работают на одной машине.
Ожидаемая нагрузка — до двух одновременно работающих пользователей.

## Состояние проекта

На 6 ноября 2026 года подготовлен первоначальный проект системы.
Приложение ещё не реализовано; модель-сегментатор будет предоставлена позже.
Примеры форматов и конфигурации в документации — проектные спецификации,
а не работающие функции или готовая конфигурация сервера.

Подтверждено владельцем проекта:

- доступ к работе только после регистрации и входа;
- регистрация только по приглашению;
- отдельные слова и файлы как входные данные;
- выбор предложенного разбора и интерактивная ручная правка;
- общая редакция для словаря и независимые разметки для оценки моделей;
- хранение результатов для дальнейшей оценки качества и пополнения словарей.

## Предлагаемая архитектура

Модульное приложение на Django, PostgreSQL и отдельный фоновый процесс
обработки заданий. Страницы формирует Django; интерактивный редактор написан
на TypeScript. Nginx направляет запросы с `/morphemelab/` в приложение.
Модель загружается в процессе инференса и не занимает процессы веб-сервера.

Исходный ответ модели, версии человеческой разметки и зафиксированные
выгрузки хранятся отдельно. Повторный запуск модели не меняет уже сделанную
разметку. Все решения о технологиях пока имеют статус предложения.
