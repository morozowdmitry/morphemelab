# HTTP-интерфейс

Статус: проект операций, 2026-11-06. Полная OpenAPI-схема появится вместе
с реализацией. Это внутренний интерфейс браузерного приложения.

## Общие правила

Публичный корень — `/morphemelab/`, JSON API — `/morphemelab/api/v1/`.
Ниже пути API указаны относительно этого корня. HTML-страницы используют
тот же сервисный слой. Запросы выполняются с того же origin.

Авторизация — серверные сессии Django и защищённая cookie. Все изменяющие
запросы, включая вход, принятие приглашения и выход, защищены CSRF.
JWT и хранение токенов в localStorage не нужны. API без сессии возвращает
`401`, HTML-страницы перенаправляют на вход с безопасным локальным `next`.

Права проверяются по проекту и назначению разметки для каждого объекта,
включая кандидаты, историю и скачивание. Списки фильтруются на сервере.
Недоступный объект возвращает `404`; недопустимое действие над доступным
объектом — `403`. Непредсказуемый UUID не заменяет авторизацию.

## Операции

| Метод и путь | Действие | Кто может выполнять |
| --- | --- | --- |
| `GET projects/` | Доступные проекты | Вошедший пользователь |
| `GET projects/{id}/datasets/` | Наборы проекта | Участник проекта |
| `POST projects/{id}/imports/` | Загрузить файл и поставить проверку в очередь | Участник проекта |
| `GET imports/{id}/` | Состояние и отчёт проверки | Участник проекта |
| `POST imports/{id}/confirm/` | Опубликовать проверенный набор | Автор импорта; руководитель |
| `POST projects/{id}/words/` | Создать набор из одного слова | Участник проекта |
| `GET datasets/{id}/items/` | Строки набора, поиск, фильтры, пагинация | Участник проекта |
| `GET models/` | Разрешённые модели и возможности | Вошедший пользователь |
| `POST datasets/{id}/runs/` | Зафиксировать и запустить инференс | Автор набора; руководитель |
| `GET runs/{id}/` | Состояние, счётчики, ошибки | Участник проекта |
| `POST runs/{id}/cancel/` | Запросить отмену оставшейся обработки | Руководитель; инициатор |
| `GET runs/{id}/items/{item_id}/` | Кандидаты и ошибка конкретного слова | Участник с доступом по протоколу эксперимента |
| `POST datasets/{id}/annotation-sets/` | Создать общую или назначить независимую разметку | Руководитель; автор набора может создать общую или независимую для себя |
| `GET annotation-sets/{id}/items/` | Рабочая очередь разметки | Участник общей редакции; назначенный аннотатор; руководитель |
| `GET annotation-sets/{id}/items/{item_id}/` | Слово, текущая ревизия, кандидаты, номер версии | Те же |
| `POST annotation-sets/{id}/items/{item_id}/revisions/` | Новая ревизия | Участник общей редакции; назначенный аннотатор |
| `GET annotation-sets/{id}/items/{item_id}/revisions/` | История | Те же права чтения, что у разметки |
| `POST datasets/{id}/canonical-annotation-set/` | Выбрать общую редакцию для словаря | Руководитель |
| `POST projects/{id}/exports/` | Создать снимок и задание выгрузки | Руководитель; лексикограф в пределах доступной разметки |
| `GET exports/{id}/` | Состояние, состав и статистика снимка | Инициатор; руководитель |
| `GET exports/{id}/files/{file_id}/` | Скачать готовый файл | Повторная проверка текущих прав на весь состав выгрузки |

Лексикограф может самостоятельно пройти цикл загрузки, инференса и правки
своего материала. Назначение другим людям и смена существующей канонической
редакции остаются у руководителя. При создании первой общей разметки она
становится канонической автоматически. Один человек может совмещать роли
руководителя и лексикографа.

Отдельные HTML-маршруты: `accounts/login/`, `accounts/logout/`,
`accounts/invitations/accept/`, `accounts/password-reset/`, `admin/`.
Самостоятельного маршрута свободной регистрации нет. Приглашения и
административные сбросы пароля создаются через защищённую админку.

## Долгие операции и повторные запросы

Импорт, инференс и построение файлов выгрузки возвращают `202 Accepted`
с идентификатором объекта и `status_url`. Сохранение ревизии — короткая
синхронная транзакция с `201 Created`; повтор уже принятой операции — `200`.
Запрос статуса не держит HTTP-соединение до завершения модели.

Для создающих операций клиент отправляет `Idempotency-Key`. Сервер хранит
пользователя, область операции, ключ, хеш запроса и результат. Повтор
с тем же содержимым возвращает исходный объект; с другим — `409`.
Ключи долгих операций сохраняются минимум до завершения и ещё 24 часа.
У ревизий `operation_id` хранится весь срок жизни истории. Создание операции
и регистрация её ключа происходят атомарно.

Число одновременно ожидающих запусков ограничивается на пользователя
и проект; начальное предложение — три на пользователя. При превышении
лимита — `429` с указанием причины. Отмена идемпотентна и не стирает
уже опубликованные результаты.

## Пример сохранения

```json
{
  "operation_id": "operation-example-1",
  "base_version": 7,
  "status": "confirmed",
  "method": "edit_candidate",
  "source_candidate_id": "candidate-example-1",
  "segments": [
    {"start": 0, "end": 4, "type": "PREFIX"},
    {"start": 4, "end": 7, "type": "ROOT"},
    {"start": 7, "end": 8, "type": "SUFFIX"},
    {"start": 8, "end": 9, "type": "ENDING"}
  ],
  "comment": "Проверены границы и типы морфем."
}
```

При успехе сервер возвращает созданную ревизию, `lock_version: 8` и время
сохранения. При несовпадении версии:

```json
{
  "error": {
    "code": "REVISION_CONFLICT",
    "message": "Запись изменена после её открытия.",
    "current_version": 8,
    "current_revision_id": "revision-example-8"
  }
}
```

UI сохраняет локальный вариант, загружает актуальный и предлагает сравнение.
Автоматический повтор с новой версией недопустим: он молча затёр бы чужую работу.

## Ошибки и данные интерфейса

Общий ответ ошибки: `error.code`, `error.message`, необязательные `fields`
и `request_id`. Неверный JSON — `400`, нарушение формата/инвариантов — `422`,
конфликт состояния — `409`, превышение загрузки — `413`.
Сбой инфраструктуры — `503` без трассировки и секретов в ответе.

В JSON-ответах отдельно передаются `prediction_status`, `review_status`
и состояние задания. Все списки ограничены пагинацией, все сортировки
имеют устойчивый дополнительный ключ. URL для фронтенда генерирует сервер;
код редактора не строит адреса через абсолютные `/api/...`.
